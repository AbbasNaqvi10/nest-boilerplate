# NestJS Boilerplate

A starter backend built with NestJS and TypeScript, using MongoDB for persistence.

## Features

- JWT-based authentication (login)
- Role-based access control
- User CRUD endpoints
- MongoDB connection and CORS configuration

## Tech stack

NestJS, TypeScript, MongoDB, JWT

## Getting started

1. Install dependencies with yarn install
2. Create a .env file in the project root with your own MongoDB connection string and JWT secret (never commit this file; it is listed in .gitignore)
3. Start the dev server with yarn start:dev

## Scripts

- yarn start:dev - run with file watching
- yarn build - compile to dist
- yarn test - run unit tests
- yarn lint - lint and fix
